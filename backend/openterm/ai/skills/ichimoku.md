# Playbook: ichimoku

Goal: Ichimoku Kinko Hyo five-line system signal engine. A standalone Japanese technical-analysis school that generates trading signals from Tenkan/Kijun crossovers, cloud position, and Chikou confirmation. Pure pandas implementation.

Limits: this assistant reads market data through its tools. It cannot run code, a shell, or read files, so code blocks below are reference only (use the `quant` tool where it covers a calculation). This is analysis, not personalised investment advice.

## Purpose

A standalone Japanese technical analysis framework that uses a five-line system and the cloud to provide a complete trend-evaluation structure:

| Line | Japanese | Calculation | Meaning |
|----|------|------|------|
| Conversion line | Tenkan-sen | (9H+9L)/2 | Short-term trend |
| Base line | Kijun-sen | (26H+26L)/2 | Medium-term trend |
| Leading Span A | Senkou Span A | (Tenkan+Kijun)/2 shifted forward by 26 | Upper cloud boundary |
| Leading Span B | Senkou Span B | (52H+52L)/2 shifted forward by 26 | Lower cloud boundary |
| Lagging Span | Chikou Span | Closing price shifted backward by 26 | Trend confirmation |

## Signal Logic

Signals are triggered only on TK crossover events, with three filters:
- **Strong buy**: bullish TK cross + price above the cloud + bullish cloud (A > B)
- **Strong sell**: bearish TK cross + price below the cloud + bearish cloud (A < B)
- All other cases → stand aside

Warm-up requires 78 candles (52+26).

## Reference: five line calculation

## Ichimoku five-line calculation

### Conversion line (Tenkan-sen)
```
tenkan = (highest_high(9) + lowest_low(9)) / 2
```
The midpoint of the price over the short term (about 2 weeks).

### Base line (Kijun-sen)
```
kijun = (highest_high(26) + lowest_low(26)) / 2
```
The midpoint of the price over the medium term (about 1 month). The base line is also the "equilibrium point" of the price.

### Leading Span A (Senkou Span A)
```
span_a = (tenkan + kijun) / 2  # shifted forward 26 periods
```
Leading Span A is the average of the Tenkan-sen and the Kijun-sen, drawn 26 periods ahead.

### Leading Span B (Senkou Span B)
```
span_b = (highest_high(52) + lowest_low(52)) / 2  # shifted forward 26 periods
```
Leading Span B is the 52-period midpoint, drawn 26 periods ahead.

### Lagging Span (Chikou Span)
```
chikou = close  # drawn 26 periods back
```
The current closing price, drawn 26 periods back. It confirms the trend: a Lagging Span above the price is bullish, below the price is bearish.

### The cloud (Kumo)

The area between Leading Span A and Leading Span B is called the cloud (Kumo).
- A > B: bullish cloud (usually drawn in green)
- A < B: bearish cloud (usually drawn in red)
- The thickness of the cloud shows the strength of support or resistance.

## Reference: signal system

## Ichimoku signal system

### TK cross (the core signal)

#### Bullish cross
The Tenkan-sen crosses the Kijun-sen from below:
- **Strong bullish cross**: the cross happens above the cloud.
- **Medium bullish cross**: the cross happens inside the cloud.
- **Weak bullish cross**: the cross happens below the cloud.

#### Bearish cross
The Tenkan-sen crosses the Kijun-sen from above:
- **Strong bearish cross**: the cross happens below the cloud.
- **Medium bearish cross**: the cross happens inside the cloud.
- **Weak bearish cross**: the cross happens above the cloud.

### Triple filter

This engine uses a triple filter to keep signal quality high:
1. **TK cross**: the trigger.
2. **Price against the cloud**: price above the cloud is bullish, below the cloud is bearish.
3. **Direction of the cloud**: Leading Span A > B is a bullish cloud, the opposite is a bearish cloud.

A signal is generated only when all three conditions agree.

### Warm-up requirement

At least 78 candles are needed (52 periods of calculation plus a 26-period shift) before a valid signal can be generated.
