# Playbook: elliott-wave

Goal: Elliott Wave Theory signal engine. Detects swing points through Zigzag, matches 5-wave impulse and 3-wave corrective structures, validates them with Fibonacci wave relationships, and generates trend-top / correction-complete signals. Pure in-house pandas implementation.

Limits: this assistant reads market data through its tools. It cannot run code, a shell, or read files, so code blocks below are reference only (use the `quant` tool where it covers a calculation). This is analysis, not personalised investment advice.

## Purpose

Classic wave theory based on the core assumption that markets move in fractal wave structures:

| Structure | Wave Count | Direction | Meaning |
|------|------|------|------|
| Impulse wave | 5 waves (1-2-3-4-5) | Trend-following | Main trend direction |
| Corrective wave | 3 waves (A-B-C) | Counter-trend | Pullback correction |

## Core Rules

### Three Iron Rules for Impulse Waves
1. Wave 2 cannot retrace beyond the start of wave 1
2. Wave 3 cannot be the shortest impulse wave
3. Wave 4 cannot enter the price territory of wave 1

### Fibonacci Relationships Between Waves
- Wave 2 retraces 0.5-0.618 of wave 1
- Wave 3 = wave 1 × 1.618 (most common)
- Wave 4 retraces 0.382 of wave 3
- Wave 5 ≈ the length of wave 1

## Signal Logic

- **5-wave advance completed** → sell (trend top)
- **ABC pullback completed** → buy (correction finished)
- **Wave 3 in progress** → stay with the trend (no reversal signal is generated)

## Parameters

| Parameter | Default | Description |
|------|--------|------|
| swing_window | 10 | Rolling window for swing-point detection |
| fib_tolerance | 0.15 | Tolerance for Fibonacci ratios |
| min_wave_bars | 5 | Minimum number of candles per wave |

## Notes

Wave theory is highly subjective, and automatic counting can yield multiple interpretations. This implementation uses a "simplest effective single interpretation" strategy and would rather miss signals than misclassify them.

## Reference: wave structure

## Wave Structure

### Impulse Wave

A 5-wave structure in the direction of the trend:

```
        5
       / \
      /   \
  3  /     \
 / \/       \
/  4         \
1
 \
  2
```

#### The three hard rules (never violated)
1. **Wave 2 never breaks the start of wave 1**: the wave 2 retracement cannot go beyond the starting point of wave 1
2. **Wave 3 is never the shortest**: wave 3 must be longer than at least one of wave 1 and wave 5
3. **Wave 4 does not enter wave 1's territory**: the low of wave 4 cannot fall below the high of wave 1

#### Common characteristics
- Wave 1: the trend starts, usually weak
- Wave 2: a deep pullback, but it does not break the start of wave 1
- Wave 3: the strongest and longest wave, usually on rising volume
- Wave 4: a shallow pullback that alternates with wave 2 (if wave 2 was a sharp drop, wave 4 moves sideways)
- Wave 5: the last wave, often with divergence

### Corrective Wave

A 3-wave structure against the trend:

```
A
 \
  \
   B
  /
 /
C
```

#### ABC structure
- **Wave A**: the first pullback, while the market is still optimistic
- **Wave B**: a rebound that fails to break the prior high
- **Wave C**: the final decline, usually equal in length to wave A

#### Corrective variants
- Zigzag: 5-3-5, the most common
- Flat: 3-3-5
- Triangle: 3-3-3-3-3

## Reference: fibonacci wave relationships

## Fibonacci Relationships Between Waves

### Impulse wave relationships

#### Wave 2 vs wave 1
- Common retracements: 0.5, 0.618
- Maximum retracement: 0.786 (beyond that it is probably not wave 2)

#### Wave 3 vs wave 1
- Most common: 1.618 × wave 1
- Others: 1.0, 2.618 × wave 1
- Wave 3 is the most powerful wave

#### Wave 4 vs wave 3
- Common retracement: 0.382
- Others: 0.236, 0.5
- Wave 4 is usually the shallowest pullback

#### Wave 5 vs wave 1
- Most common: equal to the length of wave 1
- Others: 0.618, 1.618 × wave 1
- Wave 5 can "fail" (not exceed the high of wave 3)

### Corrective wave relationships

#### Wave C vs wave A
- Most common: equal to the length of wave A
- Other: 1.618 × wave A

#### Wave B retracement
- Zigzag: retraces 0.382-0.618 of wave A
- Flat: retraces 0.786-1.0 of wave A

### Ratios used by this engine

| Relationship | Target | Tolerance |
|------|--------|------|
| Wave 2 / wave 1 | 0.5-0.618 | ±15% |
| Wave 3 / wave 1 | 1.618 | ±15% |
| Wave 4 / wave 3 | 0.382 | ±15% |
| Wave 5 / wave 1 | 1.0 | ±15% |
