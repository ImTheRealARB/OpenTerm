# Wave structure

## Impulse wave

A 5-wave structure that moves in the direction of the trend:

```
        5
       / \
      /   \
  3  /     \
 / \/       \
/  4         \
1
 \
  2
```

### The three iron rules (never violated)
1. **Wave 2 does not break the start of wave 1**: the retracement of wave 2 cannot go beyond the starting point of wave 1.
2. **Wave 3 is not the shortest**: wave 3 must be longer than at least one of wave 1 or wave 5.
3. **Wave 4 does not enter the territory of wave 1**: the low of wave 4 cannot be below the high of wave 1.

### Typical characteristics
- Wave 1: the trend starts, usually weak.
- Wave 2: a deep pullback, but it does not break the start of wave 1.
- Wave 3: the strongest and longest wave, usually with rising volume.
- Wave 4: a shallow pullback that alternates with wave 2 (for example, if wave 2 is a sharp drop, wave 4 moves sideways).
- Wave 5: the last wave; a divergence may appear.

## Corrective wave

A 3-wave structure that moves against the trend:

```
A
 \
  \
   B
  /
 /
C
```

### ABC structure
- **Wave A**: the first pullback; the market is still seen as bullish.
- **Wave B**: a rebound that fails to break the previous high.
- **Wave C**: the final decline, usually equal to the length of wave A.

### Corrective wave variants
- Zigzag: 5-3-5, the most common.
- Flat: 3-3-5.
- Triangle: 3-3-3-3-3.
