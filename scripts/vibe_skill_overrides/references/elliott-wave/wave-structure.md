# Wave Structure

## Impulse Wave

A 5-wave structure in the direction of the trend:

```
        5
       / \
      /   \
  3  /     \
 / \/       \
/  4         \
1
 \
  2
```

### The three hard rules (never violated)
1. **Wave 2 never breaks the start of wave 1**: the wave 2 retracement cannot go beyond the starting point of wave 1
2. **Wave 3 is never the shortest**: wave 3 must be longer than at least one of wave 1 and wave 5
3. **Wave 4 does not enter wave 1's territory**: the low of wave 4 cannot fall below the high of wave 1

### Common characteristics
- Wave 1: the trend starts, usually weak
- Wave 2: a deep pullback, but it does not break the start of wave 1
- Wave 3: the strongest and longest wave, usually on rising volume
- Wave 4: a shallow pullback that alternates with wave 2 (if wave 2 was a sharp drop, wave 4 moves sideways)
- Wave 5: the last wave, often with divergence

## Corrective Wave

A 3-wave structure against the trend:

```
A
 \
  \
   B
  /
 /
C
```

### ABC structure
- **Wave A**: the first pullback, while the market is still optimistic
- **Wave B**: a rebound that fails to break the prior high
- **Wave C**: the final decline, usually equal in length to wave A

### Corrective variants
- Zigzag: 5-3-5, the most common
- Flat: 3-3-5
- Triangle: 3-3-3-3-3
