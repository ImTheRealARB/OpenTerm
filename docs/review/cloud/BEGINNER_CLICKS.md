## Notes for the builder
- Only Welcome > "Look up a stock" and menu > WEI/N already work; every other task needs new UI. Sidebar "Start here" group should sit above the 7 category groups and the existing sidebar e2e in `gui-shell.spec.ts` asserts `.gs-head` count 7 (keep Start here out of `.gs-head`, or update that test).
- Mock gaps that the build step must fill in the spec when it flips a test: test 8 only records the `bt/run` POST (no result frames); test 6/7 assume POST `/api/alerts` and PATCH `/api/portfolios/<name>` shapes from `net/api.ts` (`api8`).
- Playwright note: a `test.fail()` test must fail by assertion, not timeout (timeouts count as real failures), hence `test.use({ actionTimeout: 3000 })` in the spec.
- No Q-style "Add" shortcuts count as a watchlist: the command-line prefill is typing a function code in effect.
- Port 4173 had a stale `vite preview` and port 8000 a backend running (started 17:48, not by this step); the spec only needs 4173 (reused with CI unset) and mocks every API call.
