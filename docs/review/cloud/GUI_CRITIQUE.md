# GUI critique (fresh eyes, 1600x900 @2x, GUI mode, fixtures, new user)

Shots: `/tmp/claude-0/-home-user-OpenTerm/d5ef32ec-9f7d-5d41-ad9b-bb76028f4db5/scratchpad/shots/` (names below). All 10 beginner flows ran by mouse and ended on a sensible panel.
Caveat: the fixture set has no TSLA / NVDA / AMZN / GOOGL quotes, so some "PROVIDER DOWN" / "NO DATA" rows are fixture gaps. The missing next-step text is still real.
Also: the backend DB is shared across the fresh browser contexts, so the watchlist and portfolio "empty" shots (03a, 07a) showed the saved lists, not the empty state. The empty-state buttons were not seen.

## High
1. **00-first-screen, 00b-welcome-closed: red status banners dominate every panel.** `SPY 1Y 1d CANDLE ...`, `TOP NEWS ...`, `QUOTE MONITOR ...` are solid red bars, but red means "bad / ERR" elsewhere. Color must carry meaning, and a beginner reads three red panels as three errors. The same bars carry the all-caps key legend (`J/K MOVE · ENTER OPEN ARTICLE · E CSV · F5 REFRESH`), which is a layout caption. Fix: in GUI mode restyle the panel status line (`.sl` / status-line class in `frontend/src/gui/gui.css`) to neutral grey on the panel background, hide the key legend (it lives in the `?` help), and keep red only for ERR/STALE.
2. **00-first-screen: starter watchlist shows PROVIDER DOWN, no reason, no action.** Four of six rows say `PROVIDER DOWN` with no plain line or retry. It violates "every error says what to do next". Fix: per-row cell text in `functions/quoteRows.ts` / `Grid` for GUI mode: "No price yet" plus one panel `PanelNote` ("Yahoo isn't answering for 4 names. It retries on its own.", Retry button).
3. **02-tesla-chart-1y: NO DATA gives no next step.** The note says to check the spelling or try another name. Tesla is a valid, selected name, so the advice is wrong. Fix: `components/PanelNote.tsx` caller in GP: when the symbol came from the picker, say "No chart data from <source>." with Retry and "Try AAPL" buttons (as DES does in shot 10).
4. **05-world-markets: the table is clipped on the right.** `%CHG` is cut off at the panel edge (`-(`, `+(`) and the SRC column wastes the width on `YAHOO:FI...`. The key number (percent change) is the one hidden. Fix: `functions/Board.tsx` column widths: drop SRC in GUI mode (show it in the footer) or give `%CHG` a fixed min width.
5. **08-backtest-run: jargon wall.** `ENGINE US`, `WARM-UP BARS`, `ADJ CLOSES`, `SLIP 5 BPS`, `MAX DD`, `VS BENCH -123.09%` appear with no explanation, and the glossary terms (Sharpe, drawdown) do not show as underlined terms here. `VS BENCH -123.09%` next to `TOTAL +20.02%` is also confusing. HISTORICAL SIMULATION is present (good). Fix: in `functions/BT*.tsx` summary, GUI mode: lead with one plain sentence ("$100,000 became $120,024 over 5 years; buy-and-hold made $144 more per $100"), render Sharpe / max drawdown via the `data-term` glossary markup, collapse engine/warm-up/slip into a "Details" line.
6. **06-alert: the alert panel is a paragraph of all-caps instructions.** `J/K MOVE · ENTER GP · N NEW (ALRT SYM > 200 | ...)` plus `DESKTOP NOTIFICATIONS BLOCKED BY THE BROWSER...` in the header. It is a caption explaining the layout, and a command syntax the beginner was told not to learn. Fix: in `functions/ALRT.tsx` GUI mode, hide the hint block, and show the notification-blocked state as one `PanelNote` line with an "Allow notifications" button.
