# Self-review (agent 13, read-only): regressions in the sprint diff

Scope: `git diff main..HEAD -- backend/openterm frontend/src` (58 commits at the time). Read-only; nothing run (no gates, no servers). Severity: M = medium, L = low.

## Findings likely real

1. **M. SWARM stops the whole run on spend cap / unknown price / invalid key, and then no `swarm_done` is sent** (commit 4d4c6f8, `backend/openterm/ai/swarm.py:140` `if ev["kind"] in FATAL_KINDS: ... return`).
   Scenario: a 5-role swarm hits `spend_cap` at role 4. Roles 1-3 were already paid for. The generator returns after the `error` event, so `save_events` (final = `swarm_done`) never stores the run and `audited` (FINAL_EVENTS = done, swarm_done, `audit.py:29`) never writes the ledger row. The user loses the three finished analyst notes and the audit chain has no entry for money already spent. Before this commit the swarm continued and ended with `swarm_done` (failed roles listed). The old `key_required` early return had the same shape but could not have cost anything (the first role fails before any call), so spend_cap / invalid mid-run is new.
   Suggested fix (not applied): on a fatal kind, mark the role failed, skip the remaining roles, and still emit `swarm_done` with `failed` filled and the cost so far.

2. **L-M. SWARM aborts its stream on unmount, and maximize/restore remounts the panel** (commit c820e22, `frontend/src/functions/SWARM.tsx:123`; `components/Workspace.tsx:25` renders `<Panel id={maximized}/>` instead of the layout tree, and CLAUDE.md says maximizing remounts).
   Scenario: user starts a swarm, presses the maximize key. The effect cleanup aborts the fetch; the server generator is closed (aclosing chain), the run is not stored. Before, the panel state was lost too but the server run finished and was saved. Probably intended ("stop spending unseen"), but maximize is not "closing the panel": worth a one-line decision.

3. **L. `PATH_ARGS` uses `$`, which accepts a trailing newline** (commit cd7bad7, `backend/openterm/ai/tools.py:263`). `re.match(r"^[A-Za-z0-9_\-]{1,64}$", "abc\n")` matches. Same bug class the sprint fixed with `\Z` elsewhere (bc7e06b). Not a traversal (a newline is percent-encoded into the path), so harmless in practice. Use `\Z`.

4. **L. `_wrong_type` rejects a float for `integer` arguments** (cd7bad7, `tools.py:_wrong_type`): `{"limit": 10.0}` or `{"k": 3.0}` is now a tool error ("MUST BE OF TYPE INTEGER"), while the string `"10"` passes. Some models emit `10.0`. Accept floats with `v.is_integer()`.

## Checked and found correct

- **Heartbeat** (3d0c2f9, `net/heartbeat.ts`, `net/socket.ts`): first ping never counts as missed; any message (tick, J frame) resets; dead after 2 silent intervals (about 15 s at 5 s interval); `closed` flag makes `handleClose` run once; handlers nulled before `ws.close()` so no double reconnect; `pingTimer` is shared across sockets but each `handleClose` clears it before the next socket exists. Every e2e `routeWebSocket` mock replies to `ping` with `pong` (grep: none without), so no spurious DOWN in tests. Server ignores a bare `["ping"]` and answers `["ping", t]`. Only theoretical risk: a server event loop blocked more than about 10 s with no subscriptions would be marked DOWN (reconnect is harmless).
- **Tick carry-forward** (4205941, `state/tickMerge.ts`, `ticks.ts`): carries fields 2..6 only from the previous row of the same symbol in the same frame (`pending` is cleared each flush). `flush()` already keeps the previous `Live` value for any null field across frames, so this adds no new carried-over data and no cross-session carry. Side effect: `rawListeners` (alerts) see carried `change/pct` that may be up to one frame older than the new price; negligible.
- **Cache.get_many** (40bd090): same semantics as `get` (no TTL check in either; DataService decides stale/expired afterwards), LRU `move_to_end`, `_remember` on SQLite hits, hits/misses counted per key, de-duplicates keys, 500-key chunks (below SQLite's variable limit). Unflushed `_dirty` entries are in `mem`, as in `get`.
- **Jobs** (d0204cd, 47b9b33): `_known` is checked again after the store await with no await before the insert, so racing submits dedupe. The `_done` fast path returns `cached: True` only for `state == "done"` with a result. Cancel flag reset moved to `_dispatch` (worker idle at that point, so no lost cancel; a cancel after dispatch is no longer wiped). `Worker.dead` replaces `id()`. `recent()` selects `NULL` for result; the new index is created lazily and idempotently.
- **useEnvelope conversions** (8803f4e, 67d7742): keys cover every input of each loader (HIST symbol|range|interval, ECO start|days, MACRO JSON(q), CRYP vs, N JSON(query)); stale answers dropped for `env`, `error`, `loading`; polling effects keep the `[load]` dependency (new `reload` per key). N still runs `checkNewsItems` for a dropped (stale-key) answer: it is keyed by that answer's own symbol, so harmless.
- **`\Z` regexes** (bc7e06b): all values pass through `.match` on stripped/uppercased input paths I could see; only a trailing newline is newly rejected. Portfolio `NAME_RE` and the AI `name` grammar agree (`name` lowercase allowed in the tool, uppercased/validated by the route).
- **413/422 limits** (c768a2e): `json_object` is used by 18 routes in `api.py` and 3 in `quant_routes.py`, which both map `UserDataError(too_large)` to 413 (`STATUS`). `/api/bt/import` and `/api/ai/doc/upload` read the raw body with their own 20 MB / `doc.MAX_BYTES` limits, so the 4 MB cap does not hit imports or uploads. `max_length=32` on history/profile/resolve: no multi-symbol caller found in `net/api.ts`.
- **AI tool validation**: recorded fixture turns use `quote {"symbols": "AAPL"}` (string, matches the schema); `backtest_run` symbols are an array in tests. No legitimate route in the registry is rejected (only `backtest_get` run_id and `portfolio` name are path arguments).
- **Guards**: no new import of pandas/numpy/scipy/keyring/statsmodels in the diff; no new order/gtt/holdings names; Kite change only adds `isinstance(body, dict)` checks; redaction only grew (traceback filter, uvicorn handlers, LLM error events, world payload notes). The new env-style redact pattern `[A-Z0-9_]*(?:...)=` could be quadratic on a very long underscore-separated uppercase string (error text is short and capped; L, ignore).
- **tickbuf.bucket** (2a04ef2): bucket key `t // (bar_s*1000) * bar_s` equals the old two-step floor for non-negative ms; NaN price handling (`px > h`) matches `max/min`; empty input returns `v: None`. `zip(strict=True)` turns a length mismatch into ValueError instead of IndexError (same class).
- **ai/doc.py**: `Doc.index()` cached and rebuilt if chunk count changes; `card()` does not serialize the index; `_ingest` runs parse + index in a thread; DocStore.put replaces add semantics.
- **ChartView/Grid/PORT/COMP/GP drawSave**: transferred buffers are fresh `Float64Array.slice()` copies (valid transfer); `indKey` replaces the array in deps; GP saver saves to the loaded symbol, clears on `loaded()`; COMP/PORT timers cleaned.
