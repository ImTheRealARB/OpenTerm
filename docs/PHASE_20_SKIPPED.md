# Phase 20: Vibe-Trading skills that were not ported

Source: HKUDS/Vibe-Trading `agent/src/skills` @ `8172827` (MIT). Generated by `scripts/port_vibe_skills.py`: change the script, not this file.
89 skills were read: 57 ported to `backend/openterm/ai/skills/`, 32 skipped. A skill is skipped when it needs something OpenTerm does not have:
a shell or file tools, Vibe-only stores, a broker or order tool, China A-share data, or a paid or keyed data API; or when it is written in Chinese and has no English translation.
A ported skill never names a tool that is not in the AI tool registry, and never an order, trading or broker tool. The opt-in web tools (`read_url`, `web_search`) may be named only
with the note "needs SETTINGS AI WEB ON", and the playbook then says to skip the step when web access is off. The AI never places orders.
