Status: **approved as written 2026-10-18 (roadmap defaults pre-approved by the user); built (steps 1-8).**
Source: [ROADMAP_PHASES_11-19.md](../ROADMAP_PHASES_11-19.md) "Phase 14", [FEATURE_GAP.md](../FEATURE_GAP.md), Vibe-Trading `d0db2e3`

Model: [PHASE_13.md](PHASE_13.md) (same table payload, same router/SWR/envelope, same strict-xfail test groups).

Rule that shapes every choice: **zero keys still works; a key unlocks more.** Every function below has a keyless source (all probed live
2026-10-18, fixtures recorded by `scripts/record_phase14.py`). Tradier (free sandbox key) is an *addition*: vendor Greeks on `OMON`.
Calculators (`OV`, `OSA`, `YAS`, `SWPM`, `CDSW`, `FXFA`) never default an opinion: a missing input makes the model **NOT RUNNABLE** and the panel
lists every missing field (the Phase 13 valuation rule). Anything we compute is labelled as computed.

## Decisions (defaults, approved)

| # | Decision | Default | Why |
|---|---|---|---|
| A | Payload | The Phase 13 **table payload** plus two optional additions: `charts: [{id,title,xlabel,ylabel,series:[{name,points:[[x,y|null]],dash?}],marks?:[{x,label}]}]` (smile, payoff, term structure, COT history, curves) and `heat: {id,title,xlabel,ylabel,x:[..],y:[..],z:[[..]],unit}` (IV surface, scenario grid). `ResearchPanel` renders them under the grid: charts with a small canvas XY component (no time axis needed), heat with a canvas cell map. `V` still cycles table sections, `C` cycles charts and the heat map | Speed lever 3; one panel for 15 functions; lightweight-charts has no numeric x axis |
| B | Routes | `GET /api/deriv/{omon,pcr,ov,ovdv,skew,hivg,osa,yas,swpm,cdsw,fxfa,wirp,ct,cot}` and `GET /api/rates/{curve,spreads,auctions}` (the existing `/api/rates` Treasury route keeps working); params are `symbol` plus `KEY=VALUE` query pairs; standard envelope (`data`, `source`, `stale`, `age_s`, `fallback_from`) | Same cache and fallback as `/api/research` |
| C | Clock | `Derivs.now()` is wall time; with `OPENTERM_FIXTURES=1` it is pinned to `FIXTURE_NOW` = 2026-10-18T00:00:00Z (override `OPENTERM_NOW`), so time to expiry is deterministic in tests and the bench. Time to expiry = (expiry date 16:00 New York - now) / 365 calendar days | Tests must not drift with the calendar |
| D | Chain source (`OMON`, `PCR`) | Yahoo `v7/finance/options/{sym}[?date=]` with the cookie + crumb flow (`yahoo_options`, subclass of `YahooOwnProvider`). Tradier sandbox (`tradier`, key `TRADIER_TOKEN`, capability `option_chain`) sits after Yahoo; `supports()` is false without a key. Its fixture is doc-shaped and labelled so (no key was available) | Roadmap row |
| E | Greeks and IV | Yahoo has no Greeks. Per row: IV is **solved from the bid/ask mid** by our solver when bid > 0 and ask > bid, else Yahoo's `impliedVolatility`; the source of each is a column (`IV SRC`: MID or YAHOO). Delta, gamma, theta, vega, rho are **Black-Scholes computed here** from that IV, r (US Treasury curve interpolated at the expiry, shown in the headline with its date) and q (Yahoo trailing dividend yield; if absent the column says `NO Q` and q is 0 only when typed `Q=0`). Headline says `GREEKS COMPUTED HERE (BLACK-SCHOLES, EUROPEAN), NOT VENDOR`; American early exercise is ignored and the note says so. With Tradier keyed the vendor Greeks replace ours and the label changes | Never fake data: say what each number is |
| F | `OMON` | `OMON <sym> [YYYY-MM-DD] [ITM\|OTM\|ALL]`: sections `CALLS`, `PUTS`, `STRADS` (call and put side by side by strike); expiry list in the headline (Enter on a header row is not needed: type the date); moneyness filter; open interest, volume, bid, ask, last, IV, delta, gamma, theta, vega. `PCR <sym>`: put/call ratio by volume and by open interest per expiry and in total, with the day's date. Cached 120 s | Roadmap rows |
| G | Pricer (`OV`) | Port Vibe `options.py` (BS, Greeks, Brent/Newton IV solver, Reiner-Rubinstein barrier) and `volatility.py` (Heston, Lewis integral). scipy is **not** added: `norm.cdf` is `math.erf`, `brentq` and `quad` are small pure-Python replacements in `quant/numerics.py` (Gauss-Legendre panels for Heston), so the server import stays light. Binomial (CRR, European and American) is written here (Vibe has none) and tested against BS convergence and the textbook American put. `OV <sym> K= EXP=\|T= TYPE=C\|P [IV=] [R=] [Q=] [MODEL=BS\|BIN\|AM\|HESTON\|BARRIER] [H= BARR=UO\|UI\|DO\|DI REBATE=] [V0= KAPPA= THETA= SIGMAV= RHO=] [PRICE=] [STEPS=]`. Spot is the live quote; r and q come from data with their source shown; **IV is an opinion**: typed, or the chain's ATM IV for the nearest expiry at or after T (labelled `ATM IV FROM CHAIN, EXP <date>`), else NOT RUNNABLE. `PRICE=` runs the IV solver and reports `NO IMPLIED VOL` when the quote does not pin one (Vibe's refusal rule) | Cross-checked against Vibe's own output |
| H | Surface (`OVDV`, `SKEW`) | Fit per expiry from the chain: out-of-the-money IV (puts below the forward, calls above), weighted least squares of IV on log-moneyness k = ln(K/F), `iv(k) = a + b k + c k^2` (labelled `FIT: QUADRATIC IN LOG-MONEYNESS, NOT SVI`), rejecting quotes with no two-sided market. The grid is expiries x moneyness 80%..120% with linear interpolation in total variance across expiries. Eight expiries (`pick_expiries`: the nearest, then the one closest to +7, +30, +60, +90, +180, +270 and +365 days after it; shared by `PCR`, `OVDV`, `SKEW`, `HIVG`): one Yahoo call each, concurrent, coalesced, a failed expiry is skipped and counted. `SKEW` table per expiry: ATM IV, 25-delta risk reversal and butterfly (from the fit), skew slope, plus the ATM term structure chart. **Crypto** (`OVDV BTC`, `ETH`, `SOL`) comes from Deribit `get_book_summary_by_currency` (`mark_iv`, `underlying_price` per expiry; no key) | Roadmap row |
| I | `HIVG` | Realized vol from the existing bars: close-to-close annualised (sqrt 252) for 10/20/30/60/90/252 days and Parkinson (high-low) for the same; ATM IV for each fitted expiry and the interpolated 30-day IV; IV minus RV30 (the variance risk premium, labelled). A rolling RV20 chart over one year with the IV30 as a dashed line. Free sources have no IV history, so a local table `iv_snapshots(symbol, day, iv30)` (next migration) records one point per symbol per day when `HIVG`, `OVDV` or `OMON` fetch; IV rank and percentile appear only with at least 20 snapshots and say `FROM n LOCAL SNAPSHOTS SINCE <date>` | The one place we build our own history, labelled |
| J | `OSA` | Port Vibe `options_payoff.py` (expiry payoff, breakevens, max profit and loss, scenario grid). `OSA <sym> LEGS=+1C200@5.2,-1C220 EXP=\|T= [IV=] [R=] [MULT=100] [COMM=]` (qty, C or P, strike, optional premium; no premium = BS at the entry IV) or `STRAT=BULLCALL,200,220 \| STRADDLE,200 \| CONDOR,180,190,210,220`. Sections `LEGS` (premium, per-leg Greeks), `PAYOFF` (spot grid), `SCENARIO` (spot x IV marked-to-market), `NET` (summed Greeks); chart: payoff curve; heat: scenario grid. Entry IV is typed or the chain ATM IV (labelled) | Roadmap row |
| K | Fixed income (`YAS`, `SWPM`, `CDSW`) | Port Vibe `fixedincome.py` (bond price, accrued interest, YTM solve, Macaulay and modified duration, convexity, DV01, key-rate duration, Nelson-Siegel / Svensson fit) and `credit.py` `cds_price`. `YAS CPN= MAT=YYYY-MM-DD [FREQ=2] (PX=\|YLD=) [SETTLE=] [DAYS=30/360\|ACT/ACT] [FACE=100]` (no bond database is free, so a bond is described by its terms; settle defaults to today, which is a fact, not an opinion). `SWPM`: no Vibe source, written here: fixed vs float vanilla swap on a **zero curve bootstrapped from the US Treasury par curve (labelled `TREASURY PAR CURVE AS A DISCOUNT PROXY, NOT SOFR/OIS`)** or a typed flat `CURVE=FLAT:4.2`; outputs par rate, both leg PVs, MTM, DV01, cash flows. `CDSW`: Vibe's flat-hazard engine, labelled `FLAT HAZARD, CREDIT TRIANGLE, NOT THE ISDA STANDARD MODEL` (Vibe documents its par spread lands about 0.4 percent from the quote); user inputs only, no market quotes | Roadmap row says user inputs |
| L | Rates and policy (`RATES` upgrade, `WIRP`, `FXFA`) | `RATES` keeps its US panel; new views through args: `RATES EUR` (ECB AAA spot curve, SDMX, 3M..30Y), `RATES GBP` (BoE 5/10/20Y nominal par yields; the BoE database answers plain CSV GETs, no bot check was involved), `RATES CAD` (Bank of Canada Valet benchmarks), `RATES JPY` (MoF JGB 1Y..40Y daily CSV), `RATES SPRD` (FRED OAS: IG `BAMLC0A0CM`, HY `BAMLH0A0HYM2`, BBB, BB, CCC, keyless CSV), `RATES AUCT` (TreasuryDirect auctioned and upcoming), `RATES NS <ccy>` (Nelson-Siegel fit of the shown curve with its parameters and residuals, Vibe `fit_yield_curve`). `WIRP`: fed funds futures `ZQ` contracts from Yahoo per-contract quotes (implied average rate = 100 - price, next 12 months) chained across the FOMC meeting dates (parsed from federalreserve.gov, kept in a fixture and refreshed daily) with the current effective rate and target range from FRED CSV (`DFF`, `DFEDTARU`, `DFEDTARL`); per meeting: implied rate after, change in bp, and an *illustrative* 25 bp move share (`|change| / 25`), labelled `IMPLIED BY FUTURES PRICES, NOT A PROBABILITY FORECAST`. `FXFA <PAIR> [TENORS]`: forward = spot x (1 + r_quote t) / (1 + r_base t) with money-market rates from data (USD: T-bill part of the Treasury curve; EUR: ECB 3M..1Y; JPY: MoF 1Y) or typed `R1= R2=`; labelled `COVERED INTEREST PARITY ESTIMATE, NOT A DEALER QUOTE`; a currency with no rate source and no typed rate is NOT RUNNABLE; tenors below the shortest curve point use that point flat and say so | Roadmap rows; sources probed |
| M | Futures (`CT`, `COT`) | `CT <root>`: curated root table (CL, NG, GC, SI, HG, ES, NQ, ZN, ZB, ZQ, ZC, ZS, ZW, and a few more) with Yahoo exchange suffix, month cycle and contract count; one `v8/chart` per contract (`CLZ26.NYM`), missing contracts are skipped; price, change, volume, spread to front, contango or backwardation, and roll yield per roll `(front - next) / next` annualised by *contract month spacing* (Yahoo returns no expiry date, so the note says `MONTH SPACING, NOT EXPIRY DATES`). `COT <market>`: CFTC Socrata legacy futures-only report (`6dca-aqww`): commercial, non-commercial and non-reportable longs, shorts, net, weekly change, open interest, 3-year net history chart and the percentile of today's net within it (labelled computed). Market names resolve through a curated alias table (ES, NQ, CL, GC, ZN, EUR, ...) or a substring search of CFTC market names (distinct list cached 24 h). Released Fridays; TTL 6 h | Roadmap rows; Yahoo meta has no `expireDate` |
| N | BT options engine | `OSA` structures feed `BT MKT=options`: port of Vibe `options_portfolio.py` as `bt/engines/options_portfolio.py` (BS pricing from the underlying's historical volatility), labelled `MODEL-PRICED OPTIONS (BLACK-SCHOLES ON HISTORICAL VOL), NOT MARKET QUOTES`. Built last (step 8) so a slip there cannot block the data functions | Roadmap row "feeds the BT options engine" |
| O | TTLs (s) | chain 120; surface 300; deribit 120; futures contracts 120; COT 21600; curves 3600 (ECB, BoE, BoC, MoF); spreads 21600; auctions 3600; FOMC dates 86400; HIVG 300 | Data cadence |
| P | Labels | Every table says source and age in the header (`Header`); computed numbers are named as computed (Greeks, fitted surface, CIP forwards, WIRP, roll yield, percentiles); keyed-only parts say `KEY REQUIRED: set TRADIER_TOKEN in APIKEYS` on the section | Non-negotiables |

## Functions

| Code | Args | Shows |
|---|---|---|
| `OMON` | security `[date] [ITM\|OTM\|ALL]` | Chain with computed Greeks, open interest, volume, IV |
| `PCR` | security | Put/call ratio by volume and open interest per expiry |
| `OV` | security + `KEY=VALUE` | Pricer (BS, binomial EU/AM, Heston, barrier), Greeks, IV solver; NOT RUNNABLE lists missing inputs |
| `OVDV` | security or `BTC\|ETH\|SOL` | IV surface heat map (expiry x moneyness) and smile chart; `V` cycles expiries |
| `SKEW` | security or crypto | ATM IV, 25-delta risk reversal and butterfly, skew slope per expiry; term structure chart |
| `HIVG` | security | Realized vs implied vol, variance risk premium, rolling RV chart, local IV rank |
| `OSA` | security + legs | Multi-leg payoff, breakevens, scenario grid, Greeks by leg |
| `YAS` | bond terms | Price, yield, accrued, duration, convexity, DV01, key-rate durations, cash flows |
| `SWPM` | swap terms | Vanilla swap valuation on the Treasury-derived curve or a flat curve |
| `CDSW` | CDS terms | Flat-hazard CDS valuation (user inputs) |
| `WIRP` | none | Implied policy path from fed funds futures across FOMC meetings |
| `RATES` | `[EUR\|GBP\|CAD\|JPY\|SPRD\|AUCT\|NS <ccy>]` | Non-US curves, credit spreads, auctions, Nelson-Siegel fit |
| `CT` | futures root | Term structure, contango/backwardation, roll yield |
| `COT` | market | CFTC positioning, history chart, percentile |
| `FXFA` | currency pair `[tenors]` | CIP forward estimate |

## Build steps (each ends with the five gates and a commit)

1. Spec, recorded fixtures, API and unit tests (strict-xfail per group, markers deleted by the step that makes them pass), Vibe cross-check numbers.
2. Quant library: `quant/` (numerics, options, heston, barrier, binomial, fixed income, curve fit, credit, payoff), THIRD_PARTY rows, Vibe numbers pass.
3. Options data: `yahoo_options` + Tradier adapters, `Derivs` service and `/api/deriv`, `OMON`, `PCR`, payload `charts`/`heat` and panel support.
4. `OV` pricer and `OSA` payoff panels.
5. Surface: `OVDV`, `SKEW`, `HIVG` (Yahoo and Deribit), `iv_snapshots` migration, heat map and smile canvas.
6. Rates: `YAS`, `SWPM`, `CDSW`, `FXFA`, `RATES` views (ECB, BoE, BoC, MoF, spreads, auctions, Nelson-Siegel).
7. Futures: `CT`, `WIRP`, `COT`.
8. BT options engine.
9. Docs (COMMANDS, DATA_LIMITS, CHANGELOG, PERFORMANCE), bench, real-backend smoke run, handoff, roadmap.

## Done when
Pricer tests match textbook values and Vibe's own numbers; the surface fit is tested on a recorded chain; every provider has recorded (or labelled
doc-shaped) fixtures and a DATA_LIMITS entry; each function has an e2e test with data and, where a section needs a key, the `KEY REQUIRED` path;
all gates green; bench budget for the surface render recorded; bench 24/24 (plus the new budgets).
