# Phase 19: Charting, discovery, macro, crypto (spec, 2026-10-18)

Status: approved by the standing instruction "defaults pre-approved" (HANDOFF.md). Source: `docs/ROADMAP_PHASES_11-19.md` "Phase 19".
Phase 19 has no dependency on Phases 17 and 18 (paused). Zero-key sources only: no paid API, no signup key. A source that needs a key is NOT built
(it goes to `docs/DATA_LIMITS.md` with the key it would need). Bot checks and captchas are never bypassed (so no NSE/BSE website scraping, no cookie dances).

## Rules that apply to every step
- **Never fake data.** Every new panel header names its source and as-of time; a failure shows `STALE` / `ERR` / `PROVIDER DOWN` with source and age (existing `DataService` rules).
  A fixture-backed answer in dev mode carries the existing fixture label. A fixture that is doc-shaped (the source could not be reached from this machine) is labelled
  `NOT A RECORDING` on screen, as Kite was.
- **Derived numbers say what they are.** Pattern overlays and SMC marks are `PATTERN (rule-based, not a signal)`. `PRED` odds are `MARKET-IMPLIED PROBABILITY, NOT A FORECAST`.
  `GIP` says `TICKS SINCE <time> (n)` and never claims to be exchange bars. Seasonality says the sample years.
- **Keyboard first.** Every new function and every drawing tool works from the keyboard (panel keys, `/` commands). Mouse is optional.
- **Speed.** No new work on the hot path. New backend modules import lazily; new frontend panels load through the registry (`loadModule`, never Suspense). Pure maths lives in its own
  `.ts` / `.py` file (vitest and pytest run it with no DOM and no network). Heavy scans run in the indicator worker.
- **Tests never hit the network.** Responses are recorded once by `scripts/record_phase19.py` (real responses, no keys, nothing secret in them) into `backend/tests/fixtures/`
  and routed in `providers/fixtures.py`. Probing live is allowed from scripts and by hand, never from the test suite.
- **Free-source etiquette.** Each adapter sets `rate` and a User-Agent (contact info only where the source asks, never an address written into the repo).
  DefiLlama, Binance, OKX, Polymarket, Kalshi, World Bank, DBnomics, Open-Meteo, NWS and OpenFIGI are all keyless as of 2026-10-18; verify each in its step and write the finding down.
- Tests first in each step; targeted tests while building; **one full gate per step** (`$env:CI='1'; node scripts/gates.mjs | Select-Object -Last 8`); commit with
  `Co-Authored-By: Claude Sonnet 5.5 <noreply@anthropic.com>`; `git push -u origin HEAD`. Bench numbers go to `docs/PERFORMANCE.md`. Never merge to `main`.

## Defaults decided here (change only with the user)
| Topic | Decision |
|---|---|
| Where new routes live | One new module `backend/openterm/world_routes.py` (router `/api/world/...`) plus `world/` services and `providers/` adapters, mounted in `main.py` like `quant_routes.py`. `api.py` only gains drawings. |
| Provider capabilities | New capability names (`depth`, `funding`, `liquidations`, `stablecoins`, `defi_yields`, `unlocks`, `worldstats`, `centralbank`, `energy`, `weather`, `predictions`, `figi`, `holidays`). Same `DEFAULT_ORDER` + circuit-breaker router as every other provider. |
| GP drawings | Trend line, horizontal line, fib retracement. Stored in SQLite `kv` key `drawings:<SYMBOL>` via `GET/PUT /api/drawings/{symbol}` (no migration). Pure geometry (price/time anchors, fib levels, nearest-drawing hit test) in `chart/drawings.ts`; drawn on an overlay canvas over the chart, redrawn on pan / zoom / `displayVersion`. Keys (chart panel keys): `T` trend, `H` horizontal, `B` fib; arrows move the crosshair, `Enter` places an anchor, `Tab` cycles drawings, `Del` removes, `Esc` cancels. |
| GP event markers | `GP ... EVT` toggles markers for earnings, dividends, splits taken from the Phase 13 routes already behind `EE`, `DVD`, `SPLT` (no new source). Markers are shape + letter (`E`, `D`, `S`); color carries no extra meaning. |
| GP multi-pane compare | `GP AAPL VS MSFT NVDA PANE`: each `VS` symbol in its own pane below the chart, own price scale, same time axis (lightweight-charts 5 panes). Up to 3 compare panes. Without `PANE`, `VS` keeps today's rebased overlay. |
| More studies | Added to the existing worker: ATR, STOCH, ADX, OBV, CCI, WILLR, MFI, KELT (Keltner), DONCH (Donchian), SUPERTREND, PSAR, ICHIMOKU. Same `IndicatorName` mechanism and golden-value tests. |
| Pattern overlays | `GP ... PAT:CANDLE` (doji, hammer, shooting star, engulfing, morning / evening star, harami), `PAT:ICHI` (Ichimoku cloud), `PAT:SMC` (swing highs / lows, break of structure, change of character, fair-value gaps, order-block zones). Pure functions on the OHLC arrays in `chart/patterns.ts`, run in the worker, capped at the last 5 000 bars. |
| `SEAS` | Seasonality from daily history (MAX): average return by month, by weekday, by day-of-month and by week-of-year, with hit rate, count, and the years used. Table + bar view, DOM table (like `CORR`). `SEAS AAPL`, `SEAS AAPL MONTH|WEEKDAY|DOM|WOY`. |
| `GIP` | Intraday chart built from live ticks the backend saw since the session open. Backend: per-symbol ring buffer (20 000 ticks, session reset at the symbol's market open) fed by the existing tick hub, `GET /api/world/ticks/{symbol}?bar=1s|5s|15s|1m`. The panel loads the buffer once, then appends live ticks. A symbol with no ticks (market closed, nothing subscribed) says `NO TICKS SINCE OPEN`. Bars are time-bucketed from tick prices; volume is the tick-size sum when the source gives it, else the volume column is hidden. Synthetic ticks stay labelled `SYNTHETIC`. |
| `IMAP` | Heat map of the `EQS` screener universe. Tiles sized by market cap, colored by % change (up / down theme colors, intensity by magnitude, a legend). Grouping: `IMAP` (sector, then industry), `IMAP SECTOR|INDUSTRY|COUNTRY`; filter with the same EQS tokens (`IMAP MCAP>10B`). Canvas, squarified treemap layout in pure `functions/treemap.ts`. Keys: arrows move between tiles, `Enter` opens `Q` for the tile, `Z` zooms into the group, `Backspace` out. Data comes from `/api/screener`; no new source. |
| `SECF` | Fuzzy security finder. Local scoring (prefix > word-start > subsequence, name and symbol, typo-tolerant by one edit) over the screener universe + the symbols known from `/api/search`; `SECF <text>`. Identifier lookup: a 12-char ISIN, 9-char CUSIP or 7-char SEDOL, or `FIGI:<id>`, is mapped by OpenFIGI v3 (`POST api.openfigi.com/v3/mapping`, keyless limit 25 requests / 6 s, 10 jobs each; the adapter obeys it). Result rows show symbol, name, exchange, FIGI, composite FIGI, type. `Enter` opens `DES`. No key required; a key would only raise the rate limit (not supported). |
| `ECST` / `WECO` | World statistics. `ECST <COUNTRY|ISO3> <indicator>` plots one indicator (GDP, GDPPC, CPI, UNEMP, POP, DEBT, CA, TRADE, ...) from the World Bank API v2 (keyless), with DBnomics (keyless, mirrors IMF, OECD, ECB, Eurostat) as the second source and a `DBN:<provider>/<dataset>/<series>` form for any DBnomics series. `WECO` is a country grid of the headline indicators (GDP growth, inflation, unemployment, debt / GDP, current account) for the G20, sortable, with the data year per cell (no cell silently mixes years). IMF's own JSON API is not used (unreliable); the IMF data comes through DBnomics. |
| `CENB` | Central bank calendar: rate-decision dates for the Fed, ECB, BoE, BoJ, BoC, RBA, RBI, SNB, plus the current policy rate where a keyless source gives it (ECB data portal, BoE, BoC, FRED CSV `DFEDTARU`). Dates come from each bank's published schedule page where machine-readable, else from a **dated, labelled table** in the repo (`world/cb_calendar.py`, `AS OF <date>`, source URL per bank). The table is a fixture the user can see is a table: if the current year is not in it, the panel says `CALENDAR NOT LOADED FOR <year>`. |
| FOMC in `ECO` | The Phase 14 `FomcProvider` dates are merged into the `ECO` calendar as `FOMC DECISION` rows (importance high), source `federalreserve.gov`. Fallback when the page is down: ECO unchanged and `FOMC: STALE` noted in the header. |
| Exchange holidays | `markets/hours.ts` gains `closed(market, date)`. Dates come from `GET /api/world/holidays?mkt=NY&year=` : NYSE/NASDAQ computed by rule (pure `world/nyse_holidays.py`, checked against the published list in tests, including observed-on-Friday/Monday and the Good Friday computus); other markets from Nager.Date public holidays (keyless), **labelled PUBLIC HOLIDAYS (exchange may differ)**. Market lights show `HOL` instead of OPEN/CLOSED on a holiday. Half days (day after Thanksgiving, Christmas Eve) show `EARLY`. |
| `NRG` | Energy board: WTI, Brent, Henry Hub, gasoline, diesel, US crude stocks / production where keyless. EIA's API needs a key, so spot prices and weekly series come from the **FRED CSV endpoint** (`DCOILWTICO`, `DCOILBRENTEU`, `DHHNGSP`, `GASREGW`, `WCESTUS1`, `WCRFPUS2`, `MCRFPUS2`, ... the series FRED republishes from EIA) through the existing `fred_csv` provider, plus the Yahoo futures already behind `CMDTY`. Panel: latest, change, 1y range, `NRG <series>` plots one on `FRED`'s chart. |
| `WETR` | Weather for commodity decisions. `WETR <place|lat,lon>` : 7-day forecast, plus heating / cooling degree days for a basket of demand cities, from Open-Meteo (keyless, global). US places also show NWS alerts (`api.weather.gov`, needs a User-Agent string with contact info taken from `SEC_USER_AGENT`'s mechanism; no address in the repo; absent = alerts skipped and labelled). Geocoding by Open-Meteo's geocoding API. |
| Crypto depth | New functions, all keyless: `CDEP <PAIR>` order book depth (Binance spot `/api/v3/depth`, OKX `/api/v5/market/books` as fallback; cumulative bid / ask, spread, imbalance in %), `FUND [SYM]` perp funding rates and basis (Binance `fapi/v1/premiumIndex` mark vs index, funding history `fapi/v1/fundingRate`, OKX `public/funding-rate`), `LIQ [SYM]` liquidations (OKX `public/liquidation-orders`; Binance has no REST history, so its stream is not used), `STBL` stablecoin supply by coin and chain (DefiLlama `stablecoins.llama.fi`), `DEFI [chain|project]` yields (DefiLlama `yields.llama.fi/pools`, filtered server-side to TVL > US$1M, cached 10 min, never sent whole to the browser), `UNLK` token unlocks (DefiLlama emissions endpoint: if it has moved behind a key, **UNLK is NOT BUILT** and DATA_LIMITS says why). Binance is geo-blocked in some countries (HTTP 451): the router falls back to OKX and the header names the source. |
| `PRED` | Prediction markets: Polymarket (`gamma-api.polymarket.com/markets`, public) and Kalshi (`api.elections.kalshi.com/trade-api/v2/markets`, public, no auth for reads). Rows: question, YES price as probability, volume, close date, source. `PRED <text>` filters; `Enter` shows the outcome table and a price history chart where the source gives one. Always labelled `MARKET-IMPLIED PROBABILITY, NOT A FORECAST`. Read only; no trading. |
| Non-US data | The honest zero-key fallbacks: **NSE India end-of-day bars** from the public archive files (`nsearchives.nseindia.com` daily CM bhavcopy CSV in a zip; static files, no cookie, no bot check — if the host starts demanding one the adapter is switched off and DATA_LIMITS says so) as a `history` fallback for `.NS` symbols at `1d` only, built day by day and cached in SQLite (`local_bars`-style table, labelled `NSE ARCHIVE, EOD, built from N daily files`), last 250 sessions; **AMFI mutual fund NAV** (`amfiindia.com/spages/NAVAll.txt`) as `MFNAV`-style lookups in `SECF` results. BSE (`.BO`) and other markets have no keyless static source worth the risk: Yahoo stays the only source there and DATA_LIMITS lists what each market lacks. |

## Steps (tests first in each, then code; one full gate, commit and push per step)
1. **GP studies, patterns, `SEAS` (pure code).** Tests first: golden values for the 12 new studies (hand-computed small series, cross-checked with `backend/openterm/quant` where a twin exists), candlestick pattern truth tables, Ichimoku
   lines, SMC swing / BOS / FVG on built series, seasonality tables on a synthetic 5-year series with a known monthly bias. Code: `chart/indicators.ts` additions, `chart/patterns.ts`, `functions/seasMath.ts` + `SEAS.tsx`,
   `GP` args (`PAT:`), registry rows, e2e (SEAS panel, a pattern overlay on a fixture symbol). Bench: pattern scan of 5 000 bars <= 40 ms (worker), SEAS compute on 10 000 daily bars <= 15 ms.
2. **GP drawings, event markers, panes.** Tests first: `drawings.ts` geometry (fib levels, hit test, anchor round trip across a timeframe change), `/api/drawings` round trip, marker date alignment to bars (a daily marker on a weekly chart lands on its week),
   args parse. Code: overlay canvas, keys, `EVT` markers from `EE` / `DVD` / `SPLT` routes, `PANE` compare. e2e: place a trend line with the keyboard, reload, still there. Bench: hit test over 200 drawings <= 1 ms; GP open budget unchanged.
3. **`GIP` + `IMAP`.** Tests first: tick ring buffer (reset at session open, cap, bucket math, out-of-order tick), `/api/world/ticks`, squarified treemap (areas sum to the canvas, no overlap, min tile size rule, aspect ratios bounded), `IMAP` grouping and
   color scale. Code: `world/tickbuf.py`, route, `GIP.tsx`, `treemap.ts`, `IMAP.tsx`. e2e on the synthetic tick stream (labelled) and on the fixture screener. Bench: treemap layout of 5 000 tiles <= 30 ms, IMAP paint <= 16 ms after layout.
4. **`SECF` + OpenFIGI.** Tests first: fuzzy scorer ranking cases, identifier kind detection (ISIN / CUSIP / SEDOL check digits), OpenFIGI request batching + rate obey (fake clock), response parse, NOT FOUND and 429 handling. Code: `secf/` pure scorer, `providers/openfigi.py`, route, `SECF.tsx`. e2e with fixtures.
5. **Macro: `ECST`, `WECO`, `CENB`, FOMC in `ECO`, exchange holidays.** Tests first: World Bank and DBnomics parsers on recorded responses, indicator catalogue, `WECO` year-per-cell rule, `nyse_holidays` against the published NYSE list for 2024-2027 (observed rules, Good Friday), Nager parser, `hours.closed`, `CENB` calendar table loader and the `CALENDAR NOT LOADED` case, FOMC merge into `eco`. Code: providers `worldbank.py`, `dbnomics.py`, `nager.py`, `world/` services, panels, market lights `HOL` / `EARLY`, `docs/DATA_LIMITS.md` (holiday limits). e2e for `ECST`, `WECO`, `CENB`.
6. **`NRG` + `WETR`.** Tests first: FRED-CSV series catalogue for energy, Open-Meteo forecast and geocoding parsers, degree-day maths, NWS alerts parser, no-User-Agent case. Code: `world/energy.py`, `providers/openmeteo.py`, `providers/nws.py`, panels, e2e.
7. **Crypto depth: `CDEP`, `FUND`, `LIQ`, `STBL`, `DEFI`, `UNLK`.** Tests first: depth cumulation / spread / imbalance maths, funding annualisation (8h and 1h intervals), basis in % and annualised, liquidation parse and aggregation, stablecoin and yield parsers (yields pre-filter on a recorded large payload, memory-safe), 451 fallback Binance -> OKX, `UNLK` availability probe. Code: providers `binance_deriv.py`, `okx.py`, `defillama.py`, panels, e2e. Probe the real endpoints with `scripts/record_phase19.py` first and write the findings in the progress log.
8. **`PRED`.** Tests first: Polymarket and Kalshi parsers (outcome prices as strings / cents), probability normalisation, label always present, closed-market filter. Code: `providers/polymarket.py`, `providers/kalshi.py`, panel, e2e.
9. **Non-US zero-key data.** Tests first: bhavcopy CSV parser on a recorded day file, symbol mapping (`RELIANCE.NS` -> `RELIANCE` series `EQ`), gap handling (holidays), cache, `history` fallback order (Yahoo first, archive when Yahoo fails or `1d`+`.NS` flagged), AMFI parser. Code: `providers/nse_archive.py`, `providers/amfi.py`, `local_bars` reuse, `SECF` MF rows, DATA_LIMITS table of what each market lacks.
10. **Close.** Full bench (existing 31 + the new Phase 19 budgets) recorded in `docs/PERFORMANCE.md`; a live keyless smoke of every new function against the real services (fix shape drift); docs (COMMANDS, CHANGELOG, DATA_LIMITS, HANDOFF, roadmap, CLAUDE.md); push; report in at most 10 lines.

Scope control: if the budget runs out, steps are cut from the END (10 stays; then 9, 8, 7 may be marked NOT BUILT in the roadmap with the reason). Steps 1-5 are the core. Any one function inside a step whose keyless source turns out unusable is
marked NOT BUILT with the reason (as `UNLK` may be); the step still closes.

## Done when (from the roadmap, made testable)
Every function in the roadmap row is built or explicitly marked NOT BUILT with a reason in `DATA_LIMITS.md`; each new function has parser tests on recorded responses, one Playwright test, and a header naming its source and as-of time;
drawings survive a reload; `IMAP` and `GIP` budgets are in the bench and pass; no new key is needed anywhere; full gate green; bench passes (a lone BT 10-year miss is rerun after a rest before it counts).
